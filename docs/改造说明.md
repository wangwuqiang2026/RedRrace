# RedTrace 前端改造说明（motion-makeover）

> 分支：`feat/motion-makeover`。本文如实记录本次「深色动效溯源控制台」改造的前后对比、动效清单、数据来源、运行方式、创新点、已知边界与参考来源。所有数字与断言均来自仓库内实测/登记材料，未编造演示数据。

## 1. 改造前后对比

改造前，`/app` 是米白色静态原型：只有问答页（`/ask`）是成品版式，其余 6 个路由是「将在阶段 X 接入 / 线框」占位状态（`tests/routes.test.ts` 旧断言的 `PHASE_TEXT` 即「阶段X / 接入 / 线框」）。改造后 7 页全部为成品视图，无占位符、无假功能、无外链图片。

| 路由 | 改造前 | 改造后（新标题 / 内容） |
|---|---|---|
| `/ask` | 米白静态问答版式，单一栏 | **溯源问答**：深色玻璃提问区 + shimmer 骨架 + 打字机答案（句末可聚焦上标）+ 冲突两卡并列 + 出处卡 + 右侧「溯源控制台」（检索雷达 / 闸门仪表 / 证据链）；真接口 `POST /api/ask` 链路不变 |
| `/cards` | 「阶段 X 接入」占位 | **来源档案库**：5 件已登记来源的 3D 翻转档案卡（hover/focus-within 翻面），逐字取自来源登记表 |
| `/timeline` | 「阶段 X 接入」占位 | **历史时间轴**：SVG 竖直曲线随滚动描绘，6 个真实事件节点沿路径分布、逐个点亮，年份数字滚动 |
| `/map` | 「阶段 X 接入」占位 | **事件地理分布**：程序化 SVG 中国示意地图，5 个真实地点双层脉冲点位，hover/focus 显示含来源标题的详情 |
| `/routes` | 「阶段 X 接入」占位 | **重走长征路**：滚动驱动的 SVG 路径绘制 + 镜头跟随（跟随点沿路径移动），6 个站点对应真实语料来源，进入站点时局部放大转场 |
| `/lesson-pack` | 「阶段 X 接入」占位 | **研学素材包**：按类别筛选的素材卡网格，切换时`:key` 重挂载触发错峰浮入，四类主题强调色 |
| `/audit` | 「阶段 X 接入」占位 | **来源审核台**：4 个 KPI 数字卡（数字滚动）、通过率环形图、来源审核表（行错峰入场） |

全局壳同步改造：`App.vue` 顶栏改为深色玻璃态 + 朱砂红渐变 logo + 当前项红底光条；`base.css` 页面底色改深色、自定义滚动条、`::selection` 红底浅字；`tokens.css` 新增全套 `--dm-*` 深色调色板（唯一色值来源，组件内零硬编码色值）。

## 2. 动效清单

所有动效统一走 `src/lib/motion.ts` 的 GSAP 工厂封装（`createReveal` / `createStagger` / `createCounter` / `createPathDraw` / `motionContext`），逐页在 `onMounted` 建立作用域、`onUnmounted` 统一 `revert()`；测试环境与 `prefers-reduced-motion` 下工厂返回 `null`，内容完整显示。

| 页面 | 动效 | 技术 |
|---|---|---|
| 全局壳 | 导航项入场依次浮入（`stagger 0.06`）；当前项红底光条 | `createStagger` + `motionContext`（GSAP）；CSS 过渡 |
| `/ask` | shimmer 骨架流光；打字机逐字揭示答案（55 字/秒，`requestAnimationFrame`）；引用跳转后来源卡 1.2s 闪烁；证据链节点回链闪烁；检索雷达旋转扫描；闸门条宽度按分数填充 | CSS `@keyframes dm-shimmer` / `cite-flash` / `dm-flash` / `dm-scan` / `dm-spin`；SVG；Vue 计算属性 |
| `/cards` | 档案卡入场错峰浮入（`stagger 0.09`）；hover / focus-within 3D 翻转 | `createStagger` + `motionContext`；CSS `transform` 过渡 + `:focus-within` |
| `/timeline` | SVG 曲线随滚动描绘；事件节点逐个点亮（`IntersectionObserver`）；年份数字滚动 | `createPathDraw`（GSAP ScrollTrigger）+ `createCounter` + `motionContext`；CSS `dm-pulse` / `dm-float` |
| `/map` | 整体入场浮入；点位双层脉冲；hover/focus 详情弹层 | `createReveal` + `motionContext`；CSS `@keyframes dm-pulse`；SVG |
| `/routes` | SVG 路线随滚动绘制（`end: 'bottom bottom'`）；镜头跟随点沿路径移动（rAF 插值，收束时缓动 450ms）；进入站点局部放大转场；节点脉冲 | `createPathDraw`（ScrollTrigger）+ `requestAnimationFrame` + `motionContext`；CSS `@keyframes map-zoom` / `dm-pulse`；SVG |
| `/lesson-pack` | 标题入场；素材卡错峰浮入，分类切换重挂载重新浮入（`stagger 0.055`） | `createReveal` / `createStagger` + `motionContext` |
| `/audit` | 4 个 KPI 数字滚动（错峰）；通过率环形；表格行错峰入场（`stagger 0.07`） | `createCounter` / `createStagger` + `motionContext`；SVG 环形 |

## 3. 数据来源

- **真实语料**：7 页所有展示数据逐字取自 `backend/data/来源登记表-样例.csv` 的 5 条来源（经 `frontend/src/api/mock/sources.ts` → `frontend/src/data/samples.ts` 归一）：
  1. `S001` 湖南郴州建成红军长征档案数据库（中国档案报，2026-10-19，官网直连核验）
  2. `S002` 红军长征记（解放军出版社，公开出版物，电子版待采集）
  3. `S003` 中国共产党历史（第三卷上册）（中共党史出版社，2024，电子版待采集）
  4. `S004` 万里征途入诗行（原载《解放军报》，人民网·中国共产党新闻网，2026-11-12，直连核验）
  5. `S005` 长沙现存最早的地方志——明·嘉靖《长沙府志》（中国方志网，2025-04-25）
- 时间轴 6 个事件、地图 5 个点位、路线 6 个站点均由上述 5 条来源派生，每条数据附 `sourceId` 指回 `S001`–`S005`，无编造地名/事件（例如「甘肃会宁」「宁夏西吉」因登记表无对应来源，明确不绘制）。
- **真实接口**：问答链路 `POST /api/ask`（经 `src/api/adapter.ts` 归一后端字段，`src/api/client.ts` 调用），无 mock 分支混进生产入口；e2e 的 `page.route` 注入只作测试夹具，分发规则与原契约样例一致。
- **样例定位**：`src/api/mock/scenarios.ts` 的 `ANSWER_*` 是**契约样例兜底**，答案/引文文本一律用「〔契约样例…〕」占位标记，明确非史实陈述，不是假回答；生产链路优先真接口。

## 4. 运行方式

本机 PATH 无可用 pnpm，使用 bundled JS 版 pnpm（v11.28.5）+ `npm_execpath`（见 `task-2-report.md` concern ①）。在 PowerShell 中：

```powershell
$NODE = "C:\Users\HP\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe"
$PNPM = "C:\Users\HP\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\pnpm\bin\pnpm.cjs"
$env:npm_execpath = $PNPM
& $NODE $PNPM --dir frontend run typecheck
& $NODE $PNPM --dir frontend run test
& $NODE $PNPM --dir frontend run build
& $NODE $PNPM --dir frontend exec playwright test
```

- 后端：`cd backend; python -m uvicorn app.main:app --app-dir . --port 8000`（`cd backend` 必须，仓库根直跑会 `ModuleNotFoundError`）。
- 前端：`& $NODE $PNPM --dir frontend dev --host 127.0.0.1`。Vite 在本机可能只绑 IPv6，若 `127.0.0.1` 不通改用 `localhost:5173`；端口被占时以终端实际输出为准。
- 沙箱说明：启动服务（esbuild spawn）需要 `danger-full-access` 沙箱；Playwright e2e 的 `webServer`/`globalSetup` 用 `DSH_PNPM_CLI` 指向同一个 `pnpm.cjs`，静态预览固定在 `127.0.0.1:8973`（4173 落在本机 Windows 保留端口段，实测 `EACCES`）。
- `agent-browser` 在此沙箱下 socket 目录不可写，不用它做验证。

## 5. 创新点

- **Scrollytelling 滚动叙事**：时间轴的曲线描绘、路线的路径绘制 + 镜头跟随均由滚动进度驱动（参考 IFF 2025 报告站「滚动即叙事、常驻顶栏锚定上下文」），叙事不是装饰性闪烁。
- **证据链可视化三件套**：问答页右侧「溯源控制台」把不可见的 RAG 过程外显为**检索雷达**（命中数）、**闸门仪表**（当前分 / 阈值 / 原因码）、**证据链**（点击节点回链出处卡并闪烁高亮），对应 RAG wireframe 的 confidence / explainability / fallback 理念与 EdgeQuake「Show Everything」透明化。
- **程序化 SVG 零外链**：地图、路线、雷达、环形图、图标全部由 SVG/CSS 生成，无外链图片、无第三方地图 API；本机对 `upload.wikimedia.org` / `images.unsplash.com` 的 HTTPS 访问不稳定（400/429/SSL 交替），故主动切断外链依赖，离线可用。
- **The Pudding 式「视觉散文」**：卡片档案翻面、研学素材编辑式排版、深色玻璃态 + 朱砂红点缀，让红色文化内容像探索而非教科书（参考 The Pudding 的 visceral emotional experience 与 Sakharov 博物馆交互叙事）。
- **无障碍与动效并存**：skip-link 首站、≥2px 焦点环、冲突两卡等权（六属性成对相等、DOM 序=视觉序）、打字机/扫描动效在 reduced-motion 下内容完整；三视口（desktop/768/375）红线断言全绿。

## 6. 已知边界（如实记录，不夸大）

以下边界取自 `RUNBOOK.md` 阶段二 / 三的「演示前声明」，本次前端改造不改变这些事实：

- **试点语料，非全量**：阶段二所有数字来自 **20 单元 / 125 卡 / 223 条目**的试点语料（9 部核心电子书无本地原件）。卡片数已达阶段一退出线 120，但条目 223/400、可解析单元 11/50 未达标；全量数字需补采原件后经用户再次授权重跑。
- **阈值可分性「重叠」未达标**：τ=0.41 在试点语料上可分性重叠，部分可答题会被分数闸门误拒；重排分永不参与闸门。API 重排真实冒烟（5 文档 0.81–0.88s、分数 0.24–0.84、尺子隔离成立）也不改变这一边界。两项边界已在 `docs/评测报告.md` 如实记录。
- **冲突组阶段四才接**：阶段三问答流水线已接真检索 + 真 LLM + 三层引用校验，但冲突组本阶段恒空（阶段四接）；前端冲突两卡组件与 e2e 红线是版式/等权能力的演练，不代表真接口当前会返回冲突数据。
- **样例兜底非真史实**：问答页 `ANSWER_*` 契约样例文本均带「〔契约样例…〕」标记，仅演示版式与信息层级；拒答参考卡、注册来源数因真接口暂无契约字段，前端不自造、以无数字变体显示。
- **视觉走查分工**：本次交付由 lead 在主会话负责启动服务 + Playwright 截图的人工视觉走查；本任务只完成门禁、e2e 与静态验证，真实截图结论以 lead 走查为准。
