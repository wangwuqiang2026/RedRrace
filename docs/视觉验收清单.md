# RedTrace 视觉验收清单

> **用法**：阶段五（三视图）、阶段六（路线/素材包）、阶段七（审核台）、阶段八（前端组装）各阶段验收时，由视觉监管（visual-qa）对照本清单逐项勾选。标注 **【红线】** 的条目违反任一即**验收不通过**，无豁免。
> **依据**：`docs/设计规范.md`（下称"规范"，引用章节号标注在每条末尾）；规范中的对比度值按 WCAG 公式计算，复核方法见规范 §3.4。
> **检查方式约定**：浏览器 DevTools 取实际渲染值；对比度用取色 + 公式或无障碍检测工具复算；键盘检查全程不用鼠标；屏幕阅读器抽查用系统讲述人/NVDA 任一。
> 每条格式：**检查什么 → 通过标准**。

---

## A. 全局基础（每次验收全过一遍）

- [ ] **A1【红线】颜色不作为唯一区分手段**：存疑、冲突、待考、拒答、审核三态、载体类型逐一检查 → 每一处语义状态都同时具备 颜色+图标+文字 三通道，遮住颜色（灰度模式打印）后信息仍可辨（规范 §2 R4、§6.2）。
- [ ] **A2【红线】史实性文字全部带引用编号**：对答案区、冲突卡、时间轴事件、地图点位、路线"为什么来"、素材包案例、审核台句子逐句扫描 → 每一句陈述史实的话句末（或就近）有可聚焦的上标编号，且编号锚点能定位到出处卡；无一处"裸史实句"（规范 §2 R2）。
- [ ] **A3 对比度抽测**：正文、引用灰、上标编号、语义徽标文字、按钮白字 × 各自动态底色 → 规范 §3.4 表所列各值（正文 ≥4.5:1，本项目设计值多数 ≥6:1；图形 ≥3:1）；灰度打印冲突卡与徽标仍可读。
- [ ] **A4 界面全中文**：全站标签、按钮、状态、空态、tooltip 截图过一遍 → 除例外白名单（RedTrace 专名、PDF/EPUB/Word、URL、模型名技术元数据）外无连续英文词（规范 §8）。
- [ ] **A5 状态词表一致**：检索界面文案 → 仅出现规范 §8 词表中的状态词（存疑/两处记载不一致/年代待考/未收录/通过/需修改/已复核/未定位），无同义漂移。
- [ ] **A6 焦点可见**：仅用键盘 Tab 遍历问答页与审核台一整轮 → 每个可交互元素都有 ≥2px 焦点环且不被固定顶栏遮挡（`scroll-padding-top` 生效）；无 `outline:none`（规范 §6.1）。
- [ ] **A7 图标规范**：抽查全部图标 → 同一 SVG 图标库（Lucide）同描边；**无 emoji 图标**；图标按钮均有可读 `aria-label`（规范 §6.4）。
- [ ] **A8 减弱动效**：开启系统 `prefers-reduced-motion` 重载 → 所有过渡直切、无滚动编排动画；图表入场动画关闭但数据立即可读（规范 §6.4/§7）。
- [ ] **A9 触摸/点击目标**：抽查按钮、chip、图表节点热区 → Web ≥24 CSS px，移动视口 ≥44px（规范 §6.1/§5.3）。
- [ ] **A10 字号底线**：任何连续阅读文本 → ≥16px；12px 仅限徽标与角注；正文行高 1.75（规范 §4.2）。
- [ ] **A11 数字对齐**：年份、耗时、通过率、时长列 → tabular/等宽数字，数值变化不引起布局抖动（规范 §4.1）。
- [ ] **A12 布局无横向溢出**：375 / 768 / 1024 / 1440 四档宽度 → 无整页横向滚动；出处卡长 URL 用 `overflow-wrap: anywhere` 消化（规范 §7）。

## B. 问答页 `/ask`

- [ ] **B1【红线】出处卡片信息完整**：对返回的每张卡按载体检查 → 电子书：徽标"电子书"+书名+出版社+出版年份+页码或章节+逐字引文；文章：徽标"文章"+标题+发布机构+发布日期+链接+逐字引文。字段任一缺失（且无"××不详"占位）即不通过（规范 §5.1.3）。
- [ ] **B2 出处卡字段顺序与层级**：并排比较两种载体卡 → 顺序固定"标题→发布者·日期→定位→引文→回链"；标题 18px 宋体 600，元数据 14px 引用灰（对比度 ≥4.5），不得倒置或同级混排。
- [ ] **B3 上标编号语义**：屏幕阅读器朗读答案一句 → 播报形如"出处 1，{来源标题}"的完整语义，而非裸数字或沉默（规范 §5.1.2/§6.3）。
- [ ] **B4 编号定位反馈**：键盘 Enter 激活任一上标 → 滚动至对应卡并有可见高亮（闪烁底色 ≤1.2s），焦点落在卡片区域（规范 §5.1）。
- [ ] **B5【红线】拒答不像报错**：提问库外人物（示例 2 场景）截图检查 → 拒答区为中性纸面底、ℹ 图标、深蓝灰文字；无红色、无 ⊗、无"错误/失败/异常/无法处理"字样、无 `role="alert"`（规范 §2 R3、§5.1.4）。
- [ ] **B6【红线】拒答不含猜测**：读拒答文案与其下参考卡 → 文案只说"未收录/暂无记载"，不得出现任何关于被问对象的事实句（哪怕带"可能"）；参考卡上方有"仅参考，不构成对该问题的回答"原句（规范 §5.1.4）。
- [ ] **B7 提交反馈与骨架**：慢网节流下提交 → 按钮即时进入 loading；>1s 出预留高度的骨架，答案到达无布局跳动（规范 §5.1.1/§7）。
- [ ] **B8 示例问题入口**：未提问状态 → 示例问题 chips 可见、可键盘操作、44px 高。

## C. 冲突并列条（问答页 + 审核台复用）

- [ ] **C1【红线】两条来源视觉等权**：触发冲突用例（示例 1 / 杀用例）→ 两张记载卡的字号、字重、色底、边框、内边距、宽度**逐项相同**；无加粗、置灰、缩小、"推荐"标记任一（规范 §2 R1、§5.2）。
- [ ] **C2 中性序号**：检查两卡标签 → 仅"记载一/记载二"，禁止"更可信/较新/仅供参考"类措辞。
- [ ] **C3【红线·阶段零 lead 裁决】固定排序可复核**：多造两组冲突数据、调换来源出版年份后复测 → 卡序恒为 **source_id 升序（纯编号序）**，出版年份、相关度、置信度一律不参与排序（年份序会让"先出版"被读成"更可信"，lead 裁决弃用）；窄屏堆叠顺序一致（规范 §5.2 第 3/4 条）。
- [ ] **C4 冲突提示条标识**：提示条存在且用语为"两处记载不一致"；外层可有色底，但**冲突卡之间**无任何颜色差异（规范 §5.2 第 5 条）。
- [ ] **C5 答案句与冲突区联动**：答案中的冲突句 → 琥珀底 + ◇ + 行内"（两处记载不一致）" + 并列两个上标，四点齐备；点任一上标可回相应记载卡。

## D. 时间轴 `/timeline`

- [ ] **D1 存疑事件标记**：含冲突/存疑事件的时间轴 → 空心菱形节点 + 标签"[存疑]"前缀文字 + 弹卡内完整说明；灰度打印下菱形与圆点仍可区分（规范 §5.3）。
- [ ] **D2 年代待考隔离**：时间粒度未知的条目 → 不出现在主轴上，列于下方"年代待考"区，区标题+说明文字齐备，按编号排序（规范 §5.3）。
- [ ] **D3 点位回链**：点击任一事件节点 → 弹出卡含出处（发布者/日期/页码或链接/引文），与问答页同一 SourceCard 组件（plan 阶段五步骤 7）。
- [ ] **D4 键盘与表格替代**：Tab 进图表 → 方向键移动节点、Enter 开详情、+/- 缩放；「表格视图」切换后可排序且 `aria-sort` 标注、内容与图形模式一致（规范 §5.3）。
- [ ] **D5 图表降级**：断网/屏蔽 ECharts 资源 → 页面不白屏，落到表格/列表视图并有中性说明；`role="img"` + 摘要文本存在（规范 §5.3/§7）。
- [ ] **D6 轴线与图形对比**：主轴线、节点色 vs 页面底 → ≥3:1（规范 §3.4 D1/D2 线）。

## E. 地图 `/map`

- [ ] **E1 点位回链**：点击任一点位 → popup 内出处卡完整（同 D3 标准）；popup 可键盘聚焦（规范 §5.4）。
- [ ] **E2【红线】未定位不画点**：对照接口返回 → 无坐标地点只出现在"未定位"列表，地图上零猜测点位；列表说明行"未完成坐标核准，不在地图上标注"存在（规范 §5.4）。
- [ ] **E3 地图降级路径**：屏蔽 GeoJSON 请求 → 自动切可排序地点列表 + 「重试」按钮；重试条用错误红版式且**仅在此故障场景**使用红色报错样式；用户主动选列表模式时无报错色调（规范 §5.4 降级两级）。
- [ ] **E4 存疑点位一致**：地图存疑点 → 与时间轴同一套"菱形+[存疑]文字"标记语言（规范 §5.4/§6.2）。
- [ ] **E5 地名直标**：桌面视口点位旁有地名文字标注，不依赖 hover 才可知（规范 §5.4）。

## F. 关系图 `/graph`

- [ ] **F1 节点类型区分**：人物/事件节点 → 形状（圆/方）+ 类型文字徽标，非纯颜色（规范 §5.5）。
- [ ] **F2 边标签中文谓词**：所有边标签为受控谓词中文名（plan 阶段五步骤 6），线型与文字并用；无未翻译标签。
- [ ] **F3 回链与降级**：节点侧栏出处回链可用；节点过多时列表视图可用（规范 §5.5）。

## G. 路线页 `/routes`

- [ ] **G1 每站三要素**：逐站检查 → 站名、"为什么来"一句话（句末上标编号）、停留时长三点齐备（规范 §5.6）。
- [ ] **G2 总时长可解释**：概要条总时长旁有构成说明；数字为等宽（规范 §5.6）。
- [ ] **G3 无坐标站不进线**：对照数据 → 路线内站点全部有坐标；页面如实显示站点数，无"完整路线"式暗示（规范 §5.6）。

## H. 素材包页与 Word 导出

- [ ] **H1 页面预览结构**：教学目标/案例/讨论题三段齐备；案例节选逐字引文 + 出处卡；讨论题挂条目（规范 §5.7）。
- [ ] **H2【红线】Word 页脚出处表**：导出文件逐页检查 → 页脚固定「资料来源：RedTrace 卡片库，见文末出处表」；文末出处表列序 = 编号|书名/标题|出版社/发布机构|出版年份/发布日期|页码·章节/链接（规范 §5.7）。
- [ ] **H3 Word 编号对应**：正文上标编号与出处表编号一一对应，无悬空编号、无表外史实句。
- [ ] **H4 导出冲突并列**：素材包若含冲突事实 → Word 中同样两值并列等样式（C1 同判准）。

## I. 审核台 `/audit`

- [ ] **I1【红线】三色非纯色**：通过/需修改/拒答徽标 → ✓/✎/⊘ 图标 + 中文状态文字 + 颜色三通道齐备；灰度打印徽标仍可区分（规范 §5.8）。
- [ ] **I5【红线·阶段零 lead 裁决】审核台"拒答"态用色**：触发无出处结论 → 徽标与底色为深蓝灰中性系（`--refusal-ink`/`--paper-muted`），**错误红在审核台任何元素上不出现**（错误红仅用于技术故障且伴随「重试」）；拒答说明文字为"该答案无可用出处"，无"错误/失败"措辞——拒答是系统正确行为，不是故障（规范 §5.8 定稿）。
- [ ] **I2 逐句状态可朗读**：屏幕阅读器逐句过 → 每句状态与原因（如"未找到支持该句的条目"）作为文本读出，不靠颜色/位置暗示。
- [ ] **I3 行信息完整**：日志行含问题、答案、逐句状态、引用卡、耗时、提示词版本；「已复核」可键盘操作且有即时反馈（规范 §5.8）。
- [ ] **I4 筛选与统计**：状态筛选 chips 选中态三重区分（边框+图标+字重）；通过率/耗时数字等宽对齐（规范 §5.8/§4.1）。

## J. 响应式与性能（阶段八整体验收）

- [ ] **J1 四档断点回归**：375/768/1024/1440 全页面截图 → 布局按规范 §7 重排，冲突卡堆叠后仍等权（C1 复验）。
- [ ] **J2 字体加载纪律（阶段零 lead 裁决：默认不加载 Web Font）**：断网加载首页 → 无任何字体 CDN 请求；界面以系统中文回退链呈现且版式不坏（字号阶梯/行高为相对值不塌陷）；子集自托管仅为阶段八条件增强，冷机验证未触发拖慢则不应出现在产物中（规范 §4.1）。
- [ ] **J3 分包与懒加载**：构建产物 → 时间轴/地图/关系图组件为独立 chunk，首屏不加载；ECharts 按需引入（规范 §7）。
- [ ] **J4 降级矩阵全走查**：按规范 §7 表逐行模拟故障（GeoJSON 挂、ECharts 挂、在线生成超 **15s** / 本地模型超 **30s**——阶段零 lead 裁决定值，阶段二/三实测校准后以新值复验）→ 每条路径落到规定的版式归属，超时降级用中性说明条而非报错红色（示例：仅检索卡片模式）。
- [ ] **J5 冷机可用**：B 档 CPU 笔记本实测 → 问答页交互无明显掉帧，图表切换 ≤1s 反馈（骨架即时出现即可，不要求 60fps 动画）。
