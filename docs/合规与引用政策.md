## 一、先定白名单（核验方法与结论）

### 1.1 核验方法

本阶段对候选机构逐条打开官网核验，区分三种证据强度，任何条目都必须标注其中一种：

| 标记 | 方法 | 是否可作为「已核验」 |
|---|---|---|
| 方式 A「直连实测」 | 用抓取工具直接打开该域名首页，读到该机构的自我标识（页头机构名、页脚主办/主管单位、ICP 备案号） | 是 |
| 方式 B「官链交叉」 | 域名取自另一个**已直连实测成功**的官方网站页脚或友情链接；目标站正文未能打开 | 是（仅限域名归属），栏目范围须另行复核 |
| 方式 C「书目/通报页」 | 出版社类专用：打开权威机构网站上的该书出版发行通报页或书目页（出版社官网、CIP 数据、ISBN 记录、国家新闻出版署备案页亦可），页面能确认书名与出版社 | 是（构成「该书确由该正规出版社出版」的依据）；**不要求出版社有独立域名** |
| 未核到 | 直连失败且没有官方交叉来源，或根本不知道该机构的站名/域名，或没有任何书目页 | 否，`verified: false`，不得入库 |

不使用「凭印象保留机构名」的条目。核验结果全部落在 `backend/data/来源白名单.yml`，每条含 `name / domain / sections / aliases / verified / verified_at / note`，另加 `verify_source` 记录实际打开的页面 URL。

### 1.4 出版社的准入口径（电子书专用）

电子书按 **出版社** 比对白名单。核验对象是「**这本书确实由该正规出版社出版**」，不要求出版社必须有独立域名（2026-11-13 lead 裁决，全文见 `docs/决策记录/000-语料来源与白名单.md` 第三节）：

1. 出版社名必须在白名单中可匹配（`name` 或 `aliases` 归一后一致）**且该条 `verified: true`**；`verified: false` 的条目视为不在白名单内，`registry.py` 直接拒绝；
2. 放行依据可以是以下任一种，且必须实际打开确认可写入 `verify_source`：① 出版社官网（含新书/书目页）；② CIP 数据；③ ISBN 记录；④ 国家新闻出版署备案页；⑤ 权威机构网站上的书目页或出版通报页；
3. **具体某一本书**还须有页面同时确认书名与出版社（能确认出版年份更好；年份确考不出时按 plan 允许在 `publish_date` 写字面值「年代不详」，但电子书类别下我们要求尽量有年份）；
4. 依据类型与页面原话摘要必须写进白名单条目的 `note`，让后续复核者不用重跑抓取就能判断证据强弱。

已按此口径实测核验的出版物（9 种，含 1 种地方志整理本、1 种证据强度需标注的人民出版社书目）见 `backend/data/语料征集清单.md` 第一节「已核实」分组。

## 二、允许来源与禁止来源

### 2.1 允许来源

| 载体 | 允许条件 | 语料层级 |
|---|---|---|
| 电子书 | 公开出版的红色文化读本、革命史料汇编、党史著作、人物传记、地方志与地情书的电子版（PDF / EPUB / TXT），**出版社与出版年份两项齐全**，且满足 §1.4 两条 | 核心 |
| 官方文章 | 党政机关、党史研究部门、官方媒体、地方志机构、档案馆公开发布的文章与史料页面，发布机构在 §1.2 白名单内（`verified: true`） | 核心 / 补充 |
| 本校官网与校史馆公开页面 | 若取得校名并完成域名核验，作为**补充**来源；未完成核验前，校史相关事实只能取自其他白名单机构，或明确标「待补」 | 补充 |
| 官方电子书库公开版 | 如中央党史和文献研究院「成果总库」ebook.dswxyjy.org.cn，可在线阅读；该类页面常不显示出版社字段，须再找出版通报补出版社与年份 | 补充（补齐信息后可升核心） |

### 2.2 禁止来源

- 无出版社或无出版信息的扫描电子书；
- 盗版下载站点、网盘来路不明文件、非正规渠道的「全集」「完整版」压缩包；
- 白名单之外的自媒体文章、公众号推文（**除非**其内容被白名单官网整篇刊发并可在官网 URL 下打开，例如「方志长沙」公众号文章被中国方志网刊载，此时以中国方志网页面为来源）；
- 无署名转载、来源不明转载、去掉出处的二次转录；
- 盗链、镜像、把他人付费库内容当作自有语料；
- 非公开档案（未开放的档案、内部文件、涉密材料）。

### 2.3 扫描版与 OCR 的附加条件

优先取文字版。扫描件必须先 OCR 再抽样校对，抽样核对原文（引文逐字一致）不合格，**该单元整体不入语料**，不进入 50 单元的下限统计。

## 三、引用格式

### 3.1 两种排版（按载体类型）

**电子书**

```
《书名》＋出版社＋出版年份＋页码或章节
例：《红军长征记》，解放军出版社，2026 年修订再版，第 X 页 / 第 X 节
```

**文章**

```
标题＋发布机构＋发布日期＋链接
例：《湖南郴州建成红军长征档案数据库》，中国档案报，2026-10-19，
    http://www.zgdazxw.com.cn/2026-10/19/content_505878.html
```

硬要求：**页码与链接二者至少有其一**。电子书只有书名出版社、没有页码或章节定位的，不得进答案；文章没有可打开 URL 的，不得进语料库。

### 3.2 出处卡片字段（与前端 `SourceCard.vue`、`Citation` 结构一致）

| 字段 | 电子书 | 文章 |
|---|---|---|
| 名称 | 书名 | 标题 |
| 发布者 | 出版社 | 发布机构 |
| 日期 | 出版年份 | 发布日期（YYYY-MM-DD） |
| 定位 | 页码 / 章节 / 段落号 | 链接（可加标题路径与锚点） |
| 逐字引文 | 必填，须能在解析原文中逐字命中 | 同左 |
| 语料层级 | 核心 / 补充 | 核心 / 补充 |

冲突条目按 plan 全局约束第 4 条并列两条来源，展示两条的名称 + 发布者 + 日期 + 定位。

### 3.3 登记表九列（`backend/data/来源登记表-样例.csv`）

| 列名 | 填法 |
|---|---|
| `source_id` | `S` + 三位流水号，全表唯一，不复用；文件与解析结果同名归档在 `data/raw/`、`data/parsed/` |
| `title` | 电子书填书名（含卷次），文章填原文标题，不改写、不加自己的概括 |
| `publisher` | 电子书填出版社全称；文章填发布机构全称，须能在白名单 `name`/`aliases` 归一后命中 |
| `publish_date` | 电子书填出版年份（如 `2026`）；文章填发布日期（如 `2026-10-19`）；实在考不出年份才允许写字面值 `年代不详`，且不得留空 |
| `url_or_path` | 电子书填 `data/raw/` 下的文件路径，尚未采集时填核验通报页 URL；文章填可打开的原页面 URL |
| `access_date` | 本次实际获取或核验日期（YYYY-MM-DD），文章必须记，防链接失效后无从核验 |
| `license_note` | 至少写「公开出版物」或「官网公开文章」，并补具体口径：版本与再版信息、原载报刊与版次、通报页 URL、转载与被刊发关系等 |
| `corpus_tier` | 只允许 `核心` 或 `补充` |
| `media_type` | 只允许 `电子书` 或 `文章` |

校验规则由 `backend/app/ingestion/registry.py` 实现：编号唯一；标题、链接或路径、获取日期非空；载体类型必填且二选一；**电子书必须有出版社与出版年份**；发布者必须在白名单内，否则抛 `ValueError` 且错误信息含 `whitelist`。

## 四、电子书版权口径（答辩主动说明）

1. 电子书**仅用于校内研究与教学**，不对外分发原文，不提供整本下载、不整本公开全文；
2. 系统对外只展示**逐字引文片段 + 出处**（书名、出版社、出版年份、页码或章节），单条引文控制在必要的最短片段内；
3. 原始文件只存项目组工作目录 `backend/data/raw/`（已 gitignore，不入版本库），仓库里只留登记表与出处信息；
4. 语料优先取**出版社官方、正规数字图书馆、馆藏电子书**与官方电子书库（如中央党史和文献研究院成果总库）的公开阅读版本，不取盗版下载件；
5. 若日后需要对外展示，先做替换：只保留公开文章，或取得授权后再上；
6. 答辩时由本项目主动说明以上四点，而不是等评委追问。

## 五、无出处不回答 与 冲突并列

### 5.1 无出处不回答（红线）

- 每条结论性句子必须绑定至少一个事实条目；每个事实条目必须绑定来源与定位（页码 / 段落号 / 标题路径 / 链接锚点）；
- 检索不到证据、证据校验后全被剔除、或最高重排分低于拒答阈值 —— 三种情况都走拒答，答复必须写明「当前知识库未收录」，不得用模型预训练知识补写；
- 拒答时可给最接近的已收录条目作参考，参考项同样带出处，且不回答未收录主体的任何事实；
- 禁止创造性补充：不改写史料原意，不补全未记载的生卒年、职务、时间、地点；数字必须与来源中的数字一致。

### 5.2 冲突并列规则

- 同一「主体 + 谓词」在不同来源出现不可兼容的取值时，成组标「两处记载不一致 / 存疑」；
- 展示时**两条来源同时列出**，各带自己的名称、发布者、日期、定位与引文，系统不得判定谁对，也不得写成「可能为某年某月」式的取舍；
- 粒度差异不算冲突（如「1949 年」与「1949 年 4 月」可兼容时取细粒度并留痕）；
- 时间轴、地图、关系图与路线推荐中，涉冲突点位同样标「存疑」；
- 想让冲突可检出，同一事实必须至少有两个不同来源单元记载 —— 这是采集时的硬要求（详见 `backend/data/语料征集清单.md`）。
